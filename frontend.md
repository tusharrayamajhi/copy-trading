# Core Design Principles

## 1. Minimalism First

Always prefer:
- clean layouts
- whitespace
- typography hierarchy
- spacing consistency

Avoid:
- excessive gradients
- too many glows
- random neon colors
- unnecessary animations
- cluttered cards
