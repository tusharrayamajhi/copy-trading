On-Chain Flow

The core logic resides in a custom Anchor program. When a trader signals a swap, the Vault PDA interacts with the Jupiter Aggregator. Investors deposit into the Vault and receive "Share Tokens" which represent their equity. Withdrawals calculate profit and distribute commissions to the trader and platform automatically.

Off-Chain Flow

We use a PostgreSQL database to cache on-chain state for instant UI performance. A synchronization engine listens for Solana transaction signatures, fetches the instruction data, and updates the database. This allows for complex PnL calculations and historical charting that would be too slow/expensive to do purely on-chain.
